# 素晴日 HD Switch 简体中文移植 · 和谐版

> **本分支 = 和谐版（屏蔽指定 CG 与语音）**。完整版见 `master` 分支与 Release ①。

## 安装（推荐）

下载 Release **②【和谐版】完整安装包（三卷，独立目录）**，三卷解压后把 `switch/` 复制到 SD 卡根目录。**与完整版可同时安装**，互不覆盖。

安装后目录：

```
switch/subahibi_clean_hd_qa_chs/
├─ Subahibi_clean.nro         主程序（hbmenu 显示：素晴日 和谐版）
├─ chs/                        4 个词典（覆盖层 13,794 条，其中 79 条为占位句）
├─ font/NotoSansSC_wght.ttf
└─ story/                      54 个 data*.arc（13 个已改写）+ ipl._bp
```

## 屏蔽范围

- **图像**：284 个指定 id（491 个条目）替换为纯黑 1280×960 帧
- **语音**：248 条替换为静音
- **文本**：79 条成人向正文替换为「（此处内容已省略）」

> ⚠️ **不是全年龄版**：只屏蔽指定的 284 个 id；背景、立绘、未列出的 CG 均保持原样。

## 独立目录是怎么做到的

主程序里 25 处路径字符串 `sdmc:/switch/subahibi_pc_native_hd_qa` 全部改写为 `sdmc:/switch/subahibi_clean_hd_qa_chs`。两者**长度完全相同（24 字符）**，属于纯字节覆盖，无 NUL 填充，文件大小与段偏移不变，未重编 NRO。

逐字节比对：差异 567 字节 / 41 段，其中 25 段正好 15 字节（路径串），其余为 NACP 标题字段。

## 已知限制

1. 不是全年龄版（见上）
2. 语音屏蔽按窗口：每个 CG 引用点前后 30 行内的语音都会静音
3. 15 条超长文本仍为日文（引擎字段上限）
4. 无「默认快进」：引擎构建链断裂无法重编，这些场景需手动推进
5. 静音 OGG 未经引擎侧 Vorbis 解码验证（本地缺 libvorbis），已用头部字段比对 + ffmpeg 解码双重替代验证

## 安装流程（两个版本完全一致）

1. 三个分卷**全部下载**到同一目录
2. 逐个解压到**同一个位置**（提示合并时选「是」）
3. 把解压出的 `switch` 文件夹整个复制到 SD 卡根目录
4. 插卡开机 → hbmenu → 选对应入口 → A 启动

首次启动自动创建 `UserData/` 与 `persistent_save_slots/`。

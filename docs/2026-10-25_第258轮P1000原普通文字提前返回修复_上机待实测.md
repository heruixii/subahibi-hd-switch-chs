## 确认的源码缺陷

P996 中原 GPL2 的 WaitTextOut_DrawChar 函数在字体信息判断后少了大括号。新增的中文编码恢复语句只受 if 控制，但下一句 return 0 无条件执行，使 90:90 普通文字在字体正常时也无法进入逐字绘制。该问题在真实源码中复现并已修复。

P999 修正版本仅在字体信息失败时执行 return 0；正常分支能继续绘制。已从修改后的原 C 文件抽取判断分支进行主机测试，并对完整原 GPL2 WaitText C 源编译 AArch64；公开符号集合与 P992 相同。

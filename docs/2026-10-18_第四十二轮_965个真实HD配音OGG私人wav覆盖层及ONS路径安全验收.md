## 一、P147：从真实受保护旧ONS剧本找播放路径，而非仅猜测资源目录

从旧NS真实原nscript.dat异或0x84恢复的121701行旧ONS中文源脚本，第120956行唯一语音子程序：

    *f_1a5
        ;语音
        getparam  $1001
        dwavestop 0
        chvol 0,100
        dwave 0,"wav/"+$1001+".ogg"
    return

因此所有新批准声音命令f_1a5 "原BGI声音ID"必须能对应运行游戏根下的wav/原BGI声音ID.ogg。此前P39～P41已生成真正原HD原OGG声到旧中文原行的965个source-only f_1a5文本命令，但没有装配游戏运行wav素材。不能由来源文本、PC FFmpeg完整解码、旧NRO静态包含dwave字符串就声称Switch能实际播放。

P147对原旧NS ONS游戏目录及现有P17 extra_endafter、P17 8af、P18 Ruby11三个完整私有ONSBrowser隔离QA目录内的**松散wav/*.ogg**文件名做实测，结果分别现有松散OGG数量为1、1274、517、1274，但四个目录对当前两主线980个新HD声音ID都没有同名松散OGG（每套当前缺980个新源声音文件）。此结果严格只说明这些目录的松散wav文件，不代表查遍arc.nsa/arc1.nsa归档内资源，也不是目标ONS运行解码已验证，更不代表自动修改先前四套完整QA目录。

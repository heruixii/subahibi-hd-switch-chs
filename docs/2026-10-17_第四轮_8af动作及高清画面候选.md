- 查阅后日谈汉化补丁 UTF-8 使用说明，确认包含作者及发布说明；没有发现可直接导入的独立译文文件。其 BGI-CHS.exe 是带有保护段的 Windows PE 程序，不是普通压缩包。仍需中文文本对应关系。
- 第四轮离线质量闸门：PASS_STATIC_INTEGRITY_ONLY。18 个 Python 工具语法通过，原 PC/NS 的 91 个文件 SHA256 基线不变。

# 第318轮 覆盖层全量校对战役（抽样纠错→全量过审）

日期：2026-11-11
起点：m32（13,714 条，覆盖率 99.60%）
目标：把抽样错误率压到千分之一以下

## 一、方法

把 13,714 条覆盖层条目按**语料出现频次**排序切成 20 块（每块 700 条），前 1,000 条覆盖 29.9% 的显示量、前 4,000 条覆盖 57%，所以按权重过审能先修玩家最常看到的错。

每块派一个校对员并行处理，只输出**确有错误**的条目；回收端用 `apply_fixes.py` 校验后才允许入库：

| 校验项 | 规则 |
|---|---|
| 序号可回溯 | 序号必须能在原块里查到日文 |
| 键存在 | 日文必须原样存在于覆盖层 |
| 编码 | 中文必须 GBK 可编码、≤500 字节、无制表符、无真换行 |
| **行尾控制符** | `\n` 出现次数必须与日文一致 |
| **行首缩进** | 全角空格缩进必须与日文一致 |

后两项是第 318 轮新增的——上线后立刻拦下一条漏掉 `\n` 的修正。
